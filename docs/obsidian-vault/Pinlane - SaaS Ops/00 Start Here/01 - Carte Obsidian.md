# Carte Obsidian

## Produit

Le dossier `01 Produit` explique la vision, les utilisateurs, la promesse et les limites a ne pas franchir.

## Architecture

Le dossier `02 Architecture` explique comment le site, les APIs, la base, les workers et les agents se parlent.

## Operations

Le dossier `03 Operations` est le runbook: que faire si Railway tombe, si les mails ne partent pas, si une reservation est en retard, ou si Vercel bloque un deploy.

## Agents IA

Le dossier `04 Agents IA` decrit l'ecosysteme agentique actuel: ce qui tourne vraiment, ce qui est simule, ce qui est pret a connecter, et ce qui demande encore une vraie API IA.

## Marketing

Le dossier `05 Marketing` rassemble la logique campagnes: LinkedIn, Facebook, Instagram, email, offres centre, ton, audiences et validation.

## Tests

Le dossier `06 Tests` contient la liste des commandes et les criteres de sortie.

## Decisions

Le dossier `07 Decisions` garde les choix structurants, les questions ouvertes et les arbitrages business.

## Source Mirror

Le dossier `99 Source Mirror` contient un index lisible vers le code et une copie des docs projet non sensibles.
