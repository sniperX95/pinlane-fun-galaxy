# Limites IA reelles

## A ne pas promettre

Ne pas dire que les agents tournent avec les tokens ChatGPT Pro.

Un abonnement ChatGPT donne acces a ChatGPT dans l'interface, mais pas a une API serveur autonome pour Railway ou Vercel.

## Ce qui est possible sans API IA

- orchestrer des jobs;
- appliquer des regles;
- simuler des rushs;
- calculer des alternatives;
- envoyer des emails;
- journaliser les decisions;
- mesurer les erreurs;
- ameliorer les heuristiques.

## Ce qui demande une API IA

- generation marketing vraiment dynamique;
- analyse autonome de tendances reseaux sociaux;
- redaction intelligente d'emails selon contexte;
- agent conversationnel direction;
- analyse profonde de logs non structures.

## Option recommandee

Brancher plus tard:

- OpenAI API;
- ou Vercel AI Gateway;
- ou un provider compatible.

Garder une couche de garde-fous locale avant toute action.
